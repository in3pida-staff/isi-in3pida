RETRIEVAL BENCHMARK
Il Retrieval Benchmark misura quanto efficacemente il sistema di recupero trova le informazioni giuste in risposta a domande reali degli ospiti.
Setup Benchmark — genera embeddings dei chunk e crea le domande di test con AI
Esegui Test — esegue il benchmark e calcola le metriche
Precision@1 / @3 — % di query in cui il chunk atteso è al primo / nei primi 3 risultati
MRR (Mean Reciprocal Rank) — misura media di quanto in alto appare il risultato atteso; 1.0 = sempre al primo posto
